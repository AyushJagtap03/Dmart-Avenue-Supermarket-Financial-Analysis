# DMart Financial Analysis | Avenue Supermarts Ltd.

An independent financial analysis project built in Microsoft Excel to evaluate Avenue Supermarts Limited (DMart) using its consolidated financial statements for FY2021 and FY2022.

## Project Overview
This project reviews DMart's financial performance and position through comparative financial statements, profitability and margin analysis, liquidity and solvency measures, efficiency ratios, working-capital trends, and cash-flow analysis. An executive-style Excel dashboard brings key metrics and trends together for easier interpretation.

## Tools & Techniques
- Microsoft Excel and spreadsheet formulas
- Financial statement and year-over-year variance analysis
- Liquidity, profitability, solvency, and efficiency ratios
- Cash-flow and working-capital analysis
- Dashboard design and data visualization
- AI-assisted workflow using ChatGPT and Microsoft Copilot, with human review of calculations and interpretations

## Workbook Contents
The workbook contains 11 sheets:

1. **Project Overview** — objective, scope, methodology, and workflow
2. **Balance Sheet** — comparative consolidated balance-sheet data
3. **Profit and Loss Account** — comparative income statement data
4. **Cash Flow Statement** — comparative cash-flow data
5. **Revenue & Profitability** — revenue, expense, profit, and margin analysis
6. **Balance Sheet Analysis** — assets, liabilities, and financial-position trends
7. **Cash Flow Analysis** — operating, investing, and financing cash-flow review
8. **Working Capital Analysis** — working-capital indicators and trends
9. **Ratio Analysis** — liquidity, profitability, and efficiency ratios with interpretation
10. **Dashboard** — executive dashboard with key performance indicators and visuals
11. **Dashboard Data Engine** — supporting calculations and dashboard data

## Key Areas Examined
- Revenue and profit growth
- Profitability margins and returns
- Short-term liquidity and solvency
- Asset and working-capital efficiency
- Operating cash flow and cash-flow movements

## Period and Reporting Basis
- **Company:** Avenue Supermarts Limited (DMart)
- **Period:** FY2021–FY2022
- **Reporting basis:** Consolidated financial statements
- **Currency:** Indian rupees (₹ crore)
- **Reference:** DMart Annual Report FY2021–22

This is an independent portfolio and learning project, not an official publication by DMart. The analysis reflects FY2021–FY2022 and should not be interpreted as current investment advice.
